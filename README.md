# LLM experiments

Small, self-contained experiments with language models and text retrieval. Each project lives in its own folder with a short README and a script you can run.

| Project | What it looks at |
|---|---|
| [German medical retrieval](german_medical_retrieval_eval) | Does hybrid retrieval (BM25 + embeddings) find the right passage in German medical text more often than BM25 or embeddings alone? Evaluated with Hit@k and MRR on a small hand-written question set, with a paired bootstrap for the differences. |
